# TUROS API Catalog

The canonical machine-readable TUROS API catalog is available as JSON at [www.turos.app/docs/.well-known/api-catalog.json](https://www.turos.app/docs/.well-known/api-catalog.json).

Use that JSON catalog for automation, OpenAPI discovery, SDK routing, MCP setup, API-family inventory, availability checks, and agent workflow planning. The catalog lists `api.secapi.ai` as the production host.

This page exists as a crawler-safe fallback for clients that first request `/.well-known/api-catalog`.
