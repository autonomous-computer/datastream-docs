List annual reports

<Info>
Audience: application and coding agent.
</Info>

## Coverage and source scope

Returns the canonical annual report (10-K, or 20-F/40-F) for each issuer-year. When an Annual Report to Shareholders (ARS) exists for the same year it is attached as `sibling`. `arsKind` is `unclassified` unless the ARS opening text is available; when it is, the value is one of `tenk_reprint`, `letter_plus_tenk`, or `glossy_other`. PDF primaries are not HTML-rendered: `renderCapability` is `pdf_unrendered` and `documentUrl` points at SEC EDGAR. `letterId` is currently always null. Canonical ticker form is `BRK-B`, not `BRK.B`. Metered as `annual_report_lookup`. See [API conventions](https://docs.secapi.ai/api-conventions).
