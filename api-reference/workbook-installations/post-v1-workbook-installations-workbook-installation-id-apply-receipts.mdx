Record workbook apply receipt

<Info>
Audience: application and coding agent.
</Info>

## Coverage and source scope

Records a validated apply receipt after an approved model change set has been written into the workbook. The request is checked against the stored change set and approval record — evidence binding, workbook precondition hash, approved target references, and read-back hash — and the receipt is appended to the workbook's provenance ledger.

## Canonical metadata

- `requestId`
- `traceparent`

## Example request

<RequestExample>
```bash
curl -X POST \
  -H "x-api-key: $SECAPI_API_KEY" \
  -H "secapi-version: 2026-03-19" \
  -H "content-type: application/json" \
  -d '{}' \
  "https://api.secapi.ai/v1/workbook-installations/example-workbook-installation-id/apply-receipts"
```
</RequestExample>
