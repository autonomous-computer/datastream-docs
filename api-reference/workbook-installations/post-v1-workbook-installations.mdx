Register workbook installation

<Info>
Audience: application and coding agent.
</Info>

## Coverage and source scope

Registers an Excel or Google Sheets workbook as a durable, server-owned workbook identity used by Excel, Sheets, MCP, and API filing-to-model workflows. The server holds the record of mappings, refresh history, provenance, and audit events.

## Canonical metadata

- `requestId`
- `traceparent`

## Example request

<RequestExample>
```bash
curl -X POST \
  -H "x-api-key: $SECAPI_API_KEY" \
  -H "secapi-version: 2026-03-19" \
  -H "content-type: application/json" \
  -d '{}' \
  "https://api.secapi.ai/v1/workbook-installations"
```
</RequestExample>
