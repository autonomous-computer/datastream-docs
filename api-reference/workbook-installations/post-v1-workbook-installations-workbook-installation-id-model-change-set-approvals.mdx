Approve workbook model changes

<Info>
Audience: application and coding agent.
</Info>

## Coverage and source scope

Records an analyst approval for an immutable workbook model-change set. The approval must cover exactly the stored proposal and is bound to its evidence snapshot and workbook precondition hash; an approval audit event is appended.

## Canonical metadata

- `requestId`
- `traceparent`

## Example request

<RequestExample>
```bash
curl -X POST \
  -H "x-api-key: $SECAPI_API_KEY" \

  -d '{}' \

```
</RequestExample>
