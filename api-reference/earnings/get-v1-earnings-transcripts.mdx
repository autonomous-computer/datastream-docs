Earnings materials

<Info>
Audience: application and coding agent.
</Info>

## Coverage and source scope

Returns SEC-furnished earnings materials from 8-K Item 2.02 filings. This is an on-demand scan of EDGAR filing materials, not a complete speaker-transcript store. `contentMd` is capped at 12,000 characters; longer bodies set `contentTruncated=true` and report the full length in `contentMdChars`. `kind` mirrors `coverage` (`release_only`, `prepared_remarks`, `transcript_text`, `unusable`) and adds `shareholder_letter` for an EX-99 shareholder letter. `letterId` is currently always null. A shareholder letter is not an earnings-call transcript. Speaker-level transcripts are served by `/v1/filings/transcripts`, which is currently unavailable and returns 404. See [API conventions](https://docs.secapi.ai/api-conventions).

## Canonical metadata

- `requestId`
- `traceparent`
- `provenance`
- `freshness`
- `materialization`

<RequestExample>

```bash
  -H "secapi-version: 2026-03-19" \
  "https://api.secapi.ai/v1/earnings/transcripts"
```
</RequestExample>

## Failure posture

- treat non-2xx responses as contract-aware failures, not free-form errors
- preserve `requestId` and `traceparent` in logs and downstream reports
- if provenance or freshness metadata is present, return it unchanged so trust is not lost in the handoff
