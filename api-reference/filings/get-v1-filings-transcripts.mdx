Earnings transcripts

<Info>
Audience: application and coding agent.
</Info>

## Coverage and source scope

Lists persisted earnings-transcript records extracted from covered EX-99 filing materials, with speaker and prepared-remarks or Q&A structure where source material supports extraction. Results depend on available source materials and extraction coverage.

## Coverage and interpretation

Records are extracted from covered EX-99 filing materials, with speaker and prepared-remarks or Q&A structure where the source supports it. Coverage follows what issuers furnish, so absence of a transcript is not evidence that no call took place. Preserve filing or exhibit citations and verify material statements in the original source.

## Canonical metadata

- `id`
- `ticker`
- `cik`
- `accessionNumber`
- `exhibit`
- `fiscalPeriod`
- `callDate`
- `speakers`
- `requestId`
- `traceparent`

## Example request

<RequestExample>
```bash
curl -X GET \

  -H "secapi-version: 2026-03-19" \
  "https://api.secapi.ai/v1/filings/transcripts"
```
</RequestExample>

## Give this prompt to your agent

Use SEC API GET /v1/filings/transcripts to read earnings-transcript records extracted from covered EX-99 materials. Preserve filing or exhibit citations and verify material statements in the original source; coverage depends on available source materials and extraction quality.
</Prompt>

## Failure posture

- a `404 filings_intelligence_not_available` on the transcript store means filing intelligence is turned off for the account, not that the query matched nothing; it does not describe the endpoint's current state
- an empty `data` array from the transcript store is a coverage gap for that issuer or window, not an outage
- preserve `requestId` and `traceparent` in logs and downstream reports
