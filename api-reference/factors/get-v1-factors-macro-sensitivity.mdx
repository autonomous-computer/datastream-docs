<Info>

</Info>

## Coverage and source scope

This is an explainable research scenario, not a point-in-time empirical regression. Use it to inspect how selected factor families are expected to react under supported macro scenarios before applying portfolio judgment.

- `scenarioKey`
- `rows[].factorKey`
- `rows[].sensitivity`
- `rows[].direction`
- `topTailwinds`
- `topHeadwinds`
- `limitations`
- `summaryMd`

- `traceparent`

## Example request

<RequestExample>
```bash
curl -X GET -H "x-api-key: $SECAPI_API_KEY" -H "secapi-version: 2026-03-19" "https://api.secapi.ai/v1/factors/macro-sensitivity?country=US&scenario_key=higher_for_longer&factors=VALUE,QUALITY,MOMENTUM&response_mode=compact"
```
</RequestExample>
