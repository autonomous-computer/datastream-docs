## Coverage and source scope

Anonymous, cacheable earnings-event calendar. Rows carry only symbol, company name, report date, and session (`bmo`, `amc`, or `unspecified`); estimate and actual figures are not included. The requested window is bounded to 31 days. Returns 404 while this public embed is not enabled.
