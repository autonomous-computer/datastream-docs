IPO calendar

<Info>
Audience: application and coding agent.
</Info>

## Coverage and source scope

Anonymous, cacheable IPO event feed derived from SEC primary-source filings (S-1, F-1, 424B): company, symbol when known, form, offering type and status, filing and effective dates, and price, share, and deal-size figures as disclosed in the filing text. `exchange` is populated only for rows that have reached the market; registration statements do not reliably disclose a venue before effectiveness, and issuers that resolve only to an over-the-counter quote are left blank. Exchange is resolved from EDGAR company-exchange metadata joined on CIK, which codes NYSE American listings as `NYSE`. Returns 404 while this public embed is not enabled.
