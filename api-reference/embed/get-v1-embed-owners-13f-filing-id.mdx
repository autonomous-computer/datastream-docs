13F filing detail

<Info>
Audience: application and coding agent.
</Info>

## Coverage and source scope

Header metadata (manager, quarter, totals, previous filing id, SEC source URL) plus value-ranked holdings rows. Holdings identify securities by issuer-key slug and symbol; CUSIP/ISIN are never emitted. Each holding reports `amount` (the figure the filing carried in sshPrnamt) alongside `amountType`: "SH" when that figure is a share count, "PRN" when it is a principal/face amount on a convertible note or debt instrument, and null when the filing carried no recognizable flag. `shares` is populated only where amountType is not PRN, so a principal amount does not reach you under a share-count field. Do not label or sum `amount` as shares without checking `amountType`.

- `traceparent`
