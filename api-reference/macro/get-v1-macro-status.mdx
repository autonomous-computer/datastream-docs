Macro coverage status

<Info>
Audience: application and coding agent.
</Info>

## Coverage and source scope

Return macro runtime readiness, artifact freshness, source posture, and country support status.

## Canonical metadata

- `status`
- `generatedAt`
- `statusSource`
- `countries[].status`
- `sources[].sourceKey`
- `alerts`
- `methodology`
- `sourceRights`
- `requestId`
- `traceparent`

## Example request

<RequestExample>
```bash
curl -X GET -H "x-api-key: $SECAPI_API_KEY" -H "secapi-version: 2026-03-19" "https://api.secapi.ai/v1/macro/status?country=US&view=full"
```
</RequestExample>

## Failure posture

- treat non-2xx responses as contract-aware failures, not free-form errors
- preserve `requestId` and `traceparent` in logs and downstream reports
- if provenance or freshness metadata is present, return it unchanged so trust is not lost in the handoff
