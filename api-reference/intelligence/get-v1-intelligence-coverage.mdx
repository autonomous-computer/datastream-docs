Filing intelligence coverage

<Info>
Audience: application and coding agent.
</Info>

## Coverage and source scope

Composes a single-issuer rollup over persisted filings-intelligence stores, including tagged events, guidance, transcripts, and footnote newness. Coverage reflects available extracted records rather than an issuer's full disclosure history.

## Coverage and interpretation

The rollup composes tagged events, guidance, transcripts, and footnote newness for one issuer from the persisted filings-intelligence stores. Counts describe what has been extracted, not what the issuer has disclosed. Preserve source counts, citation fields, and request metadata, then verify coverage against the underlying filings.

## Canonical metadata

- `requestId`
- `traceparent`

## Failure posture

- preserve `requestId` and `traceparent` in logs and downstream reports
- if provenance or freshness metadata is present, return it unchanged so trust is not lost in the handoff
